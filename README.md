# 🐉 Симулятор деревни радужных драконов 🌴

Маленькая мирная ферм-игра (idle village sim) о веселой долине радужных дракончиков, вдохновленная RainWings.

## Как играть
- Открой `index.html` в браузере — и все!
- ☀️ Ловите солнечные лучи и тыкайте на фрукты: они дают 🥭 фрукты.
- 🦎 Тыкай на дракона — тренируй камуфляж и получай 🐚 краски.
- 🛖 Строй хижины, 🥚 вылупляй новых дракончиков и следи за 😊 настроением деревни.

## Как запустить локально
Просто скачай `index.html` и открой его — зависимостей и сборки нет.

## Технологии
Чистый HTML + CSS + JavaScript, шрифты Fredoka и Nunito через Google Fonts.
